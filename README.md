## 文件说明

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 给 AI 教师的执教手册：角色、上课流程、全部教学约定（日/法/满/土四线） |
| `学员档案与学习进度.md` | 学员水平与目标、学习路线、逐课进度日志 |
| `教学状态.md` | **当前进度指针**：每线上到第几课、待办、下次课计划（每课开始先读） |
| `词汇本.md` | 生词台账（分语种）＋ 复习抽查记录 |
| `web/teacher.html` | **定制教学网页**（单文件前端，对接 Kimi Code 官方 REST/WS API；部署说明见 frp-office-setup 仓库 `docs/kimi-code-web-guide.md`） |

## 维护规则
