# 语言学习档案（日语 ＋ 法语 ＋ 满语 ＋ 土耳其语）

这是我的 AI 多语教师的教学档案仓库，用于**跨设备、跨工具**无缝继续学习。

## 如何在任何地方继续上课

1. 克隆本仓库到你的设备
2. 让任意 AI 助手（Kimi Work、Claude Code、Codex、Kimi Code Web 等）先读 `AGENTS.md`（执教手册），它会指导 AI 接着读另外几个文件
3. 直接说"上课"／"上日语"／"上法语"／"上满语"／"上土耳其语"即可继续

## 文件说明

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 给 AI 教师的执教手册：角色、上课流程、全部教学约定（日/法/满/土四线） |
| `学员档案与学习进度.md` | 学员水平与目标、学习路线、逐课进度日志 |
| `教学状态.md` | **当前进度指针**：每线上到第几课、待办、下次课计划（每课开始先读） |
| `词汇本.md` | 生词台账（分语种）＋ 复习抽查记录 |

## 维护规则

- 每次课后由 AI 教师更新：进度日志 + 教学状态.md + 词汇本，然后提交一次 commit
- 建议 commit 信息格式：`第N课：主题`（如 `满语第1课：元音与转写`）
